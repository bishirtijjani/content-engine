# Example Brand Script Frameworks

## The 9 verified script structures
Bias to complex educational + storytelling (structures 2, 3, 4, 8, 9) — better follower/lead conversion. Easy structures (1) are for reach only.

**1. Easy — Action/Result** (reach only, use sparingly)
```
If you [action], you will [result]  (repeat x3)
```

**2. Complex — Step-by-step hook** (how-to / proof)
```
Did you know that if you [Step 1] [Step 2] [Step 3] … you will get [result]
```

**3. Educational — Multi-level**
```
3 Levels of [Noun]
Level 1: [name] — steps
Level 2: [name] — steps
Level 3: [name] — steps
```

**4. Storytelling — 5-Stage Challenge** (founder authority — strongest)
```
1. CHALLENGE: Is it possible to [dream result] while still [habit] in [timeframe]? X ago I tried — here's what happened.
2. EXPLORATION: I made an X-step plan: first [1], then [2], finally [3].
3. RESULT: X later I not only [dream result] but also [side effect].
4. REALIZATION: This made me realize [realization].
5. EMPOWER: If I can do [result], so can you.
```

**5. Interview / Rating**
```
Written hook: [Smart trait] rating [noun] 1–10
Interviewer asks [noun] → answer [rank] + one-line why. Repeat.
```

**6. Visual Noun List**
```
[Show image of noun] → say its name  (repeat)
```

**7. Condition → Meaning Matrix** (diagnostic / myth)
```
If your [X] looks like [X], that means [X]  (repeat)
```

**8. Timeline** (founder story / evolution)
```
[Year] — one-liner on what happened  (repeat)
```

**9. Two-Person Comparison** (hot take / myth-bust)
```
Person A does [1,2,3] — each seems logical (but is a myth)
Person B does [1,2,3] — each seems wrong (but is correct)
Results: A got [bad], B got [good]. Outro: explain the why.
```

## Hook Bank (reuse on any topic)
- **Superlative:** "If you only watch one video on [topic], watch this."
- **Speed promise:** "How to [result] in [short time]."
- **Story loop:** "[Timeframe] ago I [surprising setup]…"
- **Polarizing:** "If you still [old way], watch this."
- **Number:** "[Number]. That's how many [unit] this saves. Here's how."
- **Meta call-out:** "This is a [format] — steal it."
- **Q&A:** "'[Common question]?' Here's the real answer."
- **Mistake:** "You're doing [thing] wrong if [sign]."

## The 5× outlier rule + templatize method
Only borrow the STRUCTURE of reels that got ≥5× the creator's follower count in views (e.g. 300K followers → 1.5M+ views). Method: transcribe (gettranscribe.ai) → templatize into fill-in-the-blank → fill with Example Brand value. Never copy words.
