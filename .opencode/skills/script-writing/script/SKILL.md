# Example Brand Script

Write scripts that convert to followers and leads, not vanity views. Every script is built from the system in `references/script-frameworks.md` — read it before writing.

## Operating rules

1. **Pick the account.** `@iambishir` (founder, orange, first-person, personal + educational).
2. **Pick the pillar.** One of: Workflow Automation · Custom Software · AI Implementation · Customer Acquisition · Business Operations & Systems · (Story/Lesson — founder only).
3. **Bias to complex educational + storytelling structures.** They convert far better to followers/leads than easy repetitive formats. Use easy structures only when the user explicitly wants reach.
4. **Hook first.** The first line is the first 3 seconds — it must stop the scroll. Pull or adapt from the Hook Bank.
5. **One idea per script.** Ladder every script back to one of the three outcomes: streamline operations, automate repetitive work, or acquire more customers.

## Output format (always)

Deliver the script in this shape:

```
ACCOUNT: @iambishir
PILLAR:  <pillar>   STRUCTURE: <one of the 9, by name>

HOOK (0–3s):
<one line, scroll-stopping>

BODY:
<the script, following the chosen structure's fill-in pattern, written out in full
spoken lines — not an outline. Mark [B-ROLL: ...] and [ON-SCREEN: ...] cues where useful.>

CTA:
<one clear ask — book audit / see receptionist demo / comment keyword>

CAPTION: <1–2 lines + 3–6 hashtags>
ON-SCREEN CAPTIONS: <the key phrases to burn in, one phrase per beat, emphasis word CAPS>
```

The ON-SCREEN CAPTIONS block should follow the locked caption style (one phrase at a time, emphasis word big/own line) so it hands off cleanly to the `video-editing` skill.

## Choosing a structure

- **Story/personal (founder authority):** use Structure 4 (5-Stage Challenge) or Timeline (8).
- **How-to / teach:** Structure 2 (Step-by-step hook) or 3 (Multi-level).
- **Myth / hot take / contrarian:** Structure 9 (Two-Person Comparison) or Condition→Meaning (7).
- **Fast list / tips:** Structure 1 (Action/Result) — easy, use sparingly for reach.
- **Proof / case study (agency):** Step-by-step (2) framed as "what we did → the result."

Match the structure to intent; never force a topic into the wrong shape.

## Ready-made topics

`references/script-frameworks.md` contains the full idea + hook matrix (60+ ready cells across the 5 pillars, each with a filmable hook, tagged by account) and the 6 founder story hooks. When the user gives a vague ask ("make something about automation"), pull a specific cell instead of inventing from scratch.
